# Guía Primer Medalla Kanto

## Descripción

Este proyecto consiste en una pagina web interactiva que funciona como una guia para obtener la primera medalla de **Pokémon Rojo Fuego / Verde Hoja**. El sitio muestra paso a paso el recorrido recomendado, acompañado de imágenes, contenido multimedia, consejos aleatorios y un formulario para que el jugador pueda dejar sus datos y comentarios.

---

## Tecnologías utilizadas

* HTML
* CSS
* JavaScript

---

## Funcionalidades

* Navegacion por cada etapa de la guia mediante botones y enlaces internos.
* Visualizacion progresiva de cada paso de la aventura.
* Consejos Pokémon mostrados de forma aleatoria.
* Reproductor de audio.
* Video demostrativo del combate contra Brock.
* Tabla con informacion del equipo del líder del gimnasio.
* Formulario de datos del jugador.
* Validacion de datos mediante JavaScript.
* Diseño responsive para dispositivos móviles y tablets.

---

## Validaciones implementadas

El formulario realiza las siguientes comprobaciones:

* Usuario entre **1 y 15 caracteres**.
* Contraseña entre **5 y 10 caracteres**.
* La contraseña debe contener:

  * al menos una letra mayuscula;
  * al menos un numero;
  * al menos un caracter especial.
* El correo debe pertenecer a alguno de los siguientes dominios:
  * @gmail.com
  * @hotmail.com
  * @outlook.com
  * @yahoo.com
* El comentario no puede quedar vacío.

Las validaciones fueron desarrolladas utilizando vectores, funciones y manejo de excepciones con `try` y `catch`.
